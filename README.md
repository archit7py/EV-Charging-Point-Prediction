# ⚡ EV-Charging-Point-Prediction

A Machine Learning project that predicts the most suitable locations for Electric Vehicle (EV) charging stations based on various geographical, demographic, and infrastructure-related factors.

The goal of this project is to help governments, city planners, and businesses optimize EV charging infrastructure by identifying high-demand locations.

---

## 📌 Features

- 📊 Data preprocessing and feature engineering
- 🤖 Machine Learning model for charging point prediction
- 📈 Model evaluation using multiple performance metrics
- 📉 Data visualization and exploratory data analysis (EDA)
- 💾 Easy-to-use prediction pipeline
- 🔄 Scalable for real-world datasets

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/EV-Charging-Point-Prediction.git
```

Move into the project directory

```bash
cd EV-Charging-Point-Prediction
```

Create a virtual environment

```bash
python -m venv .venv
```

Activate the virtual environment

**Windows**

```bash
.venv\Scripts\activate
```

**Linux / macOS**

```bash
source .venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```
